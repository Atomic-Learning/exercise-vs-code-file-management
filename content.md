In this exercise, you will practice using the Visual Studio Code (VS Code) File Explorer to manage files in the VS Code interface. Follow the following steps:

1. Use the link at the top of the page to open a Codespace.
2. Once the Codespace has loaded, open the Explorer (if it is not already open) by clicking its icon in the Activity Bar.
3. Create a new file named `newfile.py`.
4. Create a new folder named `newfolder` in the `resources` folder.
5. Move the file `example.cpp` into the `resources/newfolder` folder.
6. Delete the file `resources/example.js`.
7. Rename the file `example.css` to `renamed.css`.
8. Open the file `resources/example.cpp`.

This exercise has no associated sample solution.
